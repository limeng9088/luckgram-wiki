# Luckgram 增加了哪些功能？

你在 Telegram 里用的一切，Luckgram 里都能用。下面是 Luckgram 额外增加的功能，分组和状态与 [luckgram.cc 功能介绍](https://luckgram.cc/features/)完全一致：

- **已上线**：当前版本里所有人都能用；
- **Pro 专享**：需要开通 [Luckgram Pro](pro.md#pro)；
- **已上线（Telegram 功能）**：Telegram 本身的功能，Luckgram 里用法相同。

大多数功能都可以在 **设置 → Luckgram 功能** 里单独打开或关闭。看不到某个功能时，请看[看不到某个功能](../help/feature-not-visible.md)。

## 不算作 Luckgram 功能的内容 {#what-is-not-listed-as-a-luckgram-feature}

普通的 Telegram 聊天、频道、通话、私密聊天、快拍、机器人和 Telegram Business 功能，在 Luckgram 没有增加独立流程时，仍然属于 Telegram 本身的能力。它们的行为以 Telegram 为准，并会随上游客户端的更新而变化。Telegram Premium 和 Telegram Stars 由 Telegram 销售和管理，和 Luckgram Pro 是两回事。
