# Why can't I see a Luckgram feature?

First check the feature's status in the [feature catalog](../features/README.md): features marked Available work for everyone, and features marked Pro need [Luckgram Pro](../features/pro.md#pro). If a feature isn't in the catalog, Luckgram doesn't offer it. Then check, in order:

1. **Switch:** open **Settings → Luckgram Features** and make sure the feature is turned on. Store-restricted channels, Double Bottom and call recording are off by default.
2. **Version:** update to the latest version using the [install guide](../getting-started/install.md).
3. **Where it lives:** some entry points moved. Attachments and Luckgram's input-bar tools are in the **+** panel of the input bar; Scan and Proxy settings are in the **⋮** menu at the top right of the chat list; Square and People Nearby are in the **Discover** tab; Settings is in the **Profile** tab.
4. **Pro:** a free account that taps a Pro feature sees an upgrade sheet.
5. **Account and chat:** some features need certain conditions. For example, AI posts appear only in channels where you can post, and Save in one tap doesn't appear in chats that don't allow forwarding.
6. **Network:** AI, translation fallback, People Nearby and Square need Luckgram's service. If they can't connect, check your network or [proxy](../features/sign-in-and-network.md#proxy).

## Safe refresh steps {#safe-refresh-steps}

1. Make sure important drafts and files that exist only on this device are saved.
2. Close and reopen Luckgram.
3. Switch to the affected account again.
4. Check the feature switches in **Settings → Luckgram Features**.
5. Update the app.

Read [Before you reinstall Luckgram](app-problems.md#before-you-reinstall-luckgram) before deleting the app, clearing all app data or signing out of every account.

If the feature is still missing, contact support with your platform, Luckgram version, the feature name, and a screenshot that doesn't show your phone number, sign-in codes or private messages.
