# What's new in Luckgram?

Every version's install files and release notes are published on GitHub Releases:

- [iPhone and iPad](https://github.com/limeng9088/luckgram-ios/releases)
- [Android](https://github.com/limeng9088/luckgram-android/releases)

The app tells you when a new version is available. For every feature and its status, see the [feature catalog](../features/README.md).

## Recently added {#recently-added}

November 2026:

- [Luckgram Pro](../features/pro.md#pro): more AI use and monthly AI credits (premium model), up to 50 accounts, no sponsored messages, longer chat summaries.
- [Cloud backup](../features/pro.md#cloud-backup): encrypted account backup in the cloud, restorable on iPhone and Android.
- The [Pro community](../features/pro.md#pro-community) and the [agent market](../features/ai.md#agent-market).
- The [input-bar + panel](../features/messaging.md#plus-panel): a cleaner input bar with attachments and Luckgram tools under +.
- [Scan](../features/discover.md#scan) and [proxy settings](../features/sign-in-and-network.md#proxy) moved into the chat list's ⋮ menu; the sign-in screen always has a proxy button.
- [Sign-in code help](../features/sign-in-and-network.md#login-code): shows where to find a code sent to the Telegram app.
- [Translation](../features/translation-and-voice.md#translate-in): choose the target language the first time, and it's remembered.
- The [Discover tab](../features/discover.md#discover-tab): the third tab is now Discover, and Settings moved into Profile.
