# Messaging tools

<!-- features:top -->
> The status of each feature on this page matches [Luckgram features](https://luckgram.cc/en/features/). [← Back to features](https://luckgram.cc/en/features/)
<!-- features:top:end -->

Luckgram's messaging tools cut down on repeated typing and add shortcuts for selecting, saving and forwarding messages. You can turn each one off in **Settings → Luckgram Features**.

## Input bar + panel {#plus-panel}

> **Available** · [See it on the features page](https://luckgram.cc/en/features/#plus-panel) <!-- status:plus-panel -->

The input bar keeps only the buttons you use most: emoji, the text field, voice (or round video) and **+**. Once you type something, + turns into the send button.

Tap **+** and a grid panel replaces the keyboard:

- **Photos**, **Camera**, **File**, **Location**, **Contact**, **Poll**: open Telegram's own attachment screens;
- **Quick replies**, **Voice input**, **AI writing**, **Translate**: Luckgram's features.

Swipe sideways when there is more than one page. Tap + again, or tap the text field, to get the keyboard back. Turning a Luckgram feature off removes its tile. In groups where you can't send media, Photos, Camera and File are greyed out.

Prefer the old layout, with the paperclip and a button for each feature? Turn off **Compact input bar** in **Settings → Luckgram Features**.

## Quick replies {#quick-replies}

> **Available** · [See it on the features page](https://luckgram.cc/en/features/#quick-replies) <!-- status:quick-replies -->

Save the replies you send all the time, such as "On my way!" or "Thanks, got it.", and insert them with one tap.

1. In the input bar, tap **+ → Quick replies** to open your templates.
2. Tap one to put it in the text field so you can edit it before sending; press and hold one to send it right away.
3. Or type `/` in the text field: matching templates appear above it.

Add, edit, delete or reorder templates in **Settings → Luckgram Features → Quick replies → Manage**. Templates are stored on this device for each account and are not uploaded, so they don't appear on other devices or in other Telegram apps. They are not Telegram Business quick replies.

## Forward without the sender's name {#forward-anon}

> **Available (Telegram feature)** · [See it on the features page](https://luckgram.cc/en/features/#forward-anon) <!-- status:forward-anon -->

This is a standard Telegram feature and works the same way in Luckgram. When you forward a message, choose **Hide sender's name** on the forward screen and it arrives as if you wrote it. Check captions and links before sending; removing the source doesn't give you the right to republish someone else's content.

## Select all from one person {#select-all}

> **Available** · [See it on the features page](https://luckgram.cc/en/features/#select-all) <!-- status:select-all -->

Press and hold a message and choose **Select all from <name>** (in a private chat: **Select all from them** or **Select all mine**). Luckgram selects everything that person wrote in this chat and shows the count at the top, without Telegram's limit of 100.

Then copy (text joined in time order), forward, save to Saved Messages, or delete (only messages you're allowed to delete). Large selections are processed in batches with a progress indicator.

## Save in one tap {#save-direct}

> **Available** · [See it on the features page](https://luckgram.cc/en/features/#save-direct) <!-- status:save-direct -->

Press and hold a message and tap **Save** to send it to **Saved Messages**, without opening the forward screen and looking for Saved Messages. When you select several messages, **Save** is in the bottom bar too.

The option doesn't appear in chats that don't allow forwarding, or when the message is already in Saved Messages.

**Platforms:** iOS and Android.

## Where are my stickers, and how do I get them back? {#where-are-my-stickers-and-how-do-i-get-them-back}

> **Available now.** This is a standard Telegram feature and works the same way in Luckgram.

Sticker sets you add are saved to your Telegram account, not your phone, so they appear on every device signed in to that account. Each account has its own sets: if you use several accounts, check in the account switcher that you're on the one where you added them.

Find your sticker sets in:

- **iPhone and iPad:** **Settings → Appearance → Stickers and Emoji**.
- **Android:** **Settings → Chat Settings → Stickers**.

**A set disappeared after you added new ones?** You can have up to 200 sets; adding more archives the ones you use least instead of deleting them. Open **Archived Stickers** on the same screen and tap **Add** next to the set.

**You removed a set?** Tap any sticker from that set in a chat to open the whole set, then tap the add button (for example **Add 24 Stickers**). Sticker links (`t.me/addstickers/…`) open the same way.

NFT stickers and gifts are different. If an NFT sticker or gift is gone, you may have been scammed: Telegram handles these cases at support@telegram.org.
