## Proxy settings {#proxy}

> **Available** · [See it on the features page](https://luckgram.cc/en/features/#proxy) <!-- status:proxy -->

On many networks Telegram can't connect the first time you open the app, so the code never arrives. Luckgram puts the proxy button where you can reach it:

- **While signing in:** every sign-in screen (phone number, code, two-step password, name) has a proxy icon at the top right. A grey outline means no proxy, spinning means connecting, filled means connected. Tap it to open Telegram's proxy settings, add a SOCKS5 or MTProto proxy and come back; the icon updates right away.
- **After signing in:** tap **⋮** at the top right of the chat list; **Proxy settings** is at the top of the menu, with the current status (Off, Connecting, Connected) next to it.

You can also open a `t.me/proxy` or `tg://proxy` link someone shares to add a proxy, before or after signing in. You choose and supply the proxy; Luckgram doesn't provide proxies. Use only proxies you trust.

## Sign-in code help {#login-code}

> **Available** · [See it on the features page](https://luckgram.cc/en/features/#login-code) <!-- status:login-code -->

If your account is already signed in on another device, Telegram usually sends the sign-in code to the Telegram app on that device rather than by SMS. The code screen then shows a card:

1. Open Telegram (or Luckgram) on another device that's signed in.
2. In the chat list, find the message from the official **Telegram** account (with the blue checkmark).
3. Enter the 5–6 digit code from that message.

Tap **OK** to close the card. **How can I receive the code?** explains more:

- if every device is signed out, tap Telegram's usual **Didn't get the code?** to get it by SMS instead (when Telegram allows it);
- if you can't connect, set up a [proxy](#proxy) with the icon at the top right first.

The code is only for signing in. Anyone who asks you for it, including someone claiming to be support, is trying to scam you.

**Platforms:** iOS and Android.
