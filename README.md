# Luckgram 帮助中心

Luckgram 是一款独立的 Telegram 客户端。你用现有的 Telegram 账号登录，继续使用你的 Telegram 聊天，同时 Luckgram 在支持的地方增加了多账号、隐私、更快收发消息、翻译、媒体和 AI 等工具。

Luckgram 与 Telegram 没有隶属关系。Telegram 提供底层的账号和消息服务；Luckgram 提供客户端及其附加功能。

## Luckgram 提供什么 {#what-luckgram-offers}

- **Telegram 的一切：** 你的 Telegram 聊天、频道、群组、通话、快拍和私密聊天，用法和官方应用一样。
- **账号与隐私：** 免费最多 20 个账号（Luckgram Pro 最多 50 个）、双重空间、隐藏聊天、受限频道。
- **消息与语言：** 免费翻译收到的消息和发送前翻译、语音转文字、输入框「+」面板、快捷回复、全选某人的消息、一键收藏。
- **媒体、通话与存储：** 相册视频发成圆形视频、通话录音（附文字稿和 AI 总结）、更细的存储空间设置。
- **资料与整理：** Telegram ID 和注册时间、关键词文件夹、私人备注、共同群动态。
- **发现：** “发现”标签里的广场和附近的人，以及扫一扫。
- **Luckgram AI：** AI 助手、聊天总结、AI 回复和写作、智能体和智能体市场、AI 画图、AI 写帖子。
- **Luckgram Pro：** 更多 AI、更多账号、云备份、Pro 社群、去除赞助消息。
- **登录与网络：** 登录页就能配置代理，验证码页说明去哪里收码。

完整清单和每项的状态见[功能目录](features/README.md)，与 [luckgram.cc 功能介绍](https://luckgram.cc/features/)一致。
