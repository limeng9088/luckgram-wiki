# Luckgram 有哪些更新？

每个版本的安装包和更新说明都发布在 GitHub Releases：

- [iPhone 和 iPad 版](https://github.com/limeng9088/luckgram-ios/releases)
- [Android 版](https://github.com/limeng9088/luckgram-android/releases)

应用有新版本时会提示你更新。全部功能和当前状态见[功能目录](../features/README.md)。

## 最近新增 {#recently-added}

2026 年 11 月：

- [Luckgram Pro](../features/pro.md#pro)：更多 AI 次数和每月 AI 点数（高级模型）、最多 50 个账号、去除赞助消息、更长的聊天总结。
- [云备份](../features/pro.md#cloud-backup)：账号加密备份到云端，iPhone 和 Android 之间都能恢复。
- [Pro 社群](../features/pro.md#pro-community)和[智能体市场](../features/ai.md#agent-market)。
- [输入框「+」面板](../features/messaging.md#plus-panel)：输入框更清爽，附件和 Luckgram 功能都在「+」里。
- [扫一扫](../features/discover.md#scan)和[代理配置](../features/sign-in-and-network.md#proxy)移到聊天列表的「⋮」菜单；登录页右上角随时可以配置代理。
- [收码说明](../features/sign-in-and-network.md#login-code)：验证码发到 Telegram 应用里时，告诉你去哪里找。
- [翻译](../features/translation-and-voice.md#translate-in)：第一次翻译时选择目标语言并记住。
- [发现标签](../features/discover.md#discover-tab)：底部第三个标签换成“发现”，设置移到“个人资料”里。
