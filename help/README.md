# 帮助与安全

- [看不到某个功能](feature-not-visible.md)：检查平台、版本、套餐、地区、上线范围和账号状态。
- [应用问题](app-problems.md)：应用打不开或一直加载、提示更新但商店里没有更新、通知重复、耗电、忘记应用密码，以及使用代理。
- [群组与频道](groups-and-channels.md)：为什么能看群消息却不能发言、加入群组和频道的数量上限，以及加入时一直加载。
- [隐私与数据](privacy-and-data.md)：了解 Telegram 数据、Luckgram 功能、AI 处理、统计分析和本地存储。
- [客服与源码](support-and-source.md)：使用官方社区、政策和公开代码仓库。

手机或 SIM 卡丢了？请看[手机或 SIM 卡丢了](../getting-started/accounts.md#i-lost-my-phone-or-sim-card)。

如果账号被盗，请先在可信的 Telegram 客户端中保护好 Telegram 账号：检查活跃会话，结束陌生会话，并开启两步验证。永远不要把登录验证码或恢复用的密钥发给客服。
