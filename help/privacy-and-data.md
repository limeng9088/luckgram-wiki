# 使用 Luckgram 时，数据是怎么流转的？

Luckgram 的不同操作使用不同的系统。最稳妥、最有用的说明方式，是分清每个功能走的是哪条路径，而不是笼统地做一个隐私承诺。

| 操作 | 主要数据路径 |
|---|---|
| Telegram 聊天、频道、账号登录和普通通话 | Telegram 服务和你设备上的客户端 |
| 隐藏聊天状态、偏好设置、缓存、下载和部分快捷回复 | 主要在本地应用/设备上，具体实现有所不同 |
| Luckgram 账号服务、订阅、邀请、远程配置和功能资格 | Luckgram 服务以及相关的应用商店/服务商 |
| AI 提问、选中的聊天上下文、翻译或转写 | 根据功能不同，由 Luckgram 和/或所选的处理服务商处理 |
| 历史上与钱包关联的登录 | 与已下线的金融钱包无关；具体的旧设置请咨询客服 |
| 统计分析、诊断、归因和网站 Cookie | Luckgram 以及当前政策或应用商店中披露的服务商 |

Luckgram 当前的政策说明了为提供服务所需的收集和处理、使用情况分析、设备信息、在使用相关权限或 Telegram 功能时的联系人或位置信息，
以及你主动提供的信息。安装前也请查看 Apple 和 Google 应用商店中的隐私披露。

本帮助中心不再使用“我们不收集任何个人数据”这一旧说法，因为它与上述披露不符。

## 更安全地使用 {#safer-use}

- 检查系统权限，关闭你用不到的权限。
- 发送 AI 请求前，检查选中的上下文。
- 不要在聊天和客服工单中透露登录验证码、两步验证密码、导出的会话和钱包恢复资料。
- 记住，隐藏聊天改变的是本地界面；它不会把对话从你登录的其他设备上移除。
- 关于法律定义、保留期限、处理方和你的权利，请阅读当前的政策。
