# 为什么我看不到某个 Luckgram 功能？

大多数看不到功能的情况都与可用性有关，而不是账号出了问题。先确认这个功能是否已经[下线](../features/wallet.md)。更新应用或购买订阅都无法恢复已下线的功能。如果没有下线，请按顺序检查下面这些原因。

1. **平台：** 确认功能页面列出了 iOS、Android 或桌面端。
2. **版本：** 从[官方下载页面](https://wiki.luckgram.cc/getting-started/install.html)更新。
3. **套餐或余额：** 检查该操作是否需要 Premium、Premium+、Gems 或其他用量额度。
4. **地区或应用商店：** 法律和分发规则可能会隐藏某个功能。
5. **上线范围：** 测试版和限量上线的工具不会同时推送到所有账号。
6. **账号状态：** 有些工具需要完成 Luckgram 服务登录、符合条件的 Telegram 账号或特定的聊天权限。
7. **网络/服务商：** AI、翻译和账号洞察功能可能依赖 Telegram 消息之外的服务。

## 安全的刷新步骤 {#safe-refresh-steps}

1. 确认重要的草稿或只存在本地的文件已经保存。
2. 关闭并重新打开 Luckgram。
3. 重新切换到出问题的账号。
4. 在 Luckgram 设置中检查是否有被关闭的标签或功能开关。
5. 更新应用。

在阅读[重装 Luckgram 之前](app-problems.md#before-you-reinstall-luckgram)之前，不要删除应用、清除所有应用数据或退出所有账号。

如果功能仍然不见，请联系客服，提供平台、Luckgram 版本、功能名称，以及一张不暴露手机号、登录验证码、钱包密钥或私人消息的截图。
