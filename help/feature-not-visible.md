# 为什么我看不到某个 Luckgram 功能？

先在[功能目录](../features/README.md)里确认这个功能的状态：标注“已上线”的所有人都能用，标注“Pro 专享”的需要 [Luckgram Pro](../features/pro.md#pro)。目录里没有的功能，Luckgram 就没有提供。然后按顺序检查：

1. **开关：** 打开 **设置 → Luckgram 功能**，确认这个功能的开关是打开的。受限频道、双重空间和通话录音默认关闭。
2. **版本：** 按[安装指南](../getting-started/install.md)更新到最新版本。
3. **入口位置：** 有些入口换过位置：附件和 Luckgram 的输入框功能在输入框的 **「+」** 面板里；扫一扫和代理配置在聊天列表右上角的 **⋮** 菜单里；广场和附近的人在底部的 **发现** 标签里；设置在 **个人资料** 标签里。
4. **Pro：** Pro 专享的功能，免费账号点了会弹出升级说明。
5. **账号和聊天：** 有些功能要求特定的条件，例如 AI 写帖子只在你有发帖权限的频道里出现，一键收藏在禁止转发的聊天里不显示。
6. **网络：** AI、翻译兜底、附近的人和广场需要连接 Luckgram 的服务；连不上时请检查网络或[代理](../features/sign-in-and-network.md#proxy)。

## 安全的刷新步骤 {#safe-refresh-steps}

1. 确认重要的草稿或只存在本地的文件已经保存。
2. 关闭并重新打开 Luckgram。
3. 重新切换到出问题的账号。
4. 在 **设置 → Luckgram 功能** 里检查功能开关。
5. 更新应用。

在阅读[重装 Luckgram 之前](app-problems.md#before-you-reinstall-luckgram)之前，不要删除应用、清除所有应用数据或退出所有账号。

如果功能仍然不见，请联系客服，提供平台、Luckgram 版本、功能名称，以及一张不暴露手机号、登录验证码或私人消息的截图。
