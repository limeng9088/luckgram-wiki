# 怎么用 Luckgram 网页版？

Luckgram 网页版在浏览器里运行，不用下载安装。它用的是同一个 Telegram 账号：登录后，聊天、频道、群组和文件都在。

## 打开网页版 {#open}

1. 用电脑或手机的浏览器打开 [web.luckgram.cc](https://web.luckgram.cc)。建议使用新版的 Chrome、Edge 或 Safari。
2. 选一种方式登录：
   - **扫码：** 在手机上已登录的 Telegram 或 Luckgram 里打开 **设置 → 设备 → 连接桌面设备**，扫描页面上的二维码。
   - **手机号：** 点 **手机号登录**，输入号码和验证码。
3. 开了两步验证的账号，还要输入两步验证密码。

**验证码在哪里收？** 号码已经在别的设备上登录时，Telegram 不发短信，而是把验证码发到已登录的 Telegram 应用里，在名为 **Telegram** 的官方聊天中。号码没有在任何设备上登录时，才会发短信。

`web.luckgram.cc` 打不开时，可以用备用入口 [lgweb.cat158.com](https://lgweb.cat158.com)，内容相同。两个入口的登录状态各自独立，换入口需要重新登录。

## 安装成桌面应用 {#install}

网页版可以装成一个独立窗口的应用，有自己的图标，不带浏览器的地址栏。

| 浏览器 | 做法 |
|---|---|
| Chrome、Edge（电脑） | 点地址栏右侧的 **安装** 图标，或菜单里的 **安装 Luckgram** |
| Safari（Mac） | 菜单栏 **文件 → 添加到程序坞** |
| Chrome（Android） | 菜单 **⋮ → 添加到主屏幕** |
| Safari（iPhone、iPad） | **分享 → 添加到主屏幕** |

安装后的应用和浏览器里的网页版共用同一份登录状态。卸载应用不会退出账号；要退出，请在 **设置** 里退出登录。

## 和手机 App 有什么不同 {#differences}

网页版以 Telegram 网页版为基础，Telegram 本身的聊天、频道、群组、通话和文件收发用法相同。Luckgram 增加的功能，目前网页版只有一项：

| 功能 | 网页版 | iOS、Android App |
|---|---|---|
| [更多账号](../features/privacy.md#accounts) | 最多 20 个，不需要 Luckgram Pro | 免费 10 个，Luckgram Pro 不限数量 |
| [功能目录](../features/README.md)里的其他功能 | 暂不提供 | 提供 |
| 私密聊天（端到端加密） | 不支持，Telegram 网页版本身就没有 | 支持 |

添加账号：点左上角的菜单，选 **添加账号**。账号较多时，菜单里的账号列表可以滚动。登录满 20 个后再点，会提示「最多登录 20 个账号」。

需要网页版还没有的功能时，请用 [iOS 或 Android App](install.md)，同一个账号可以同时登录。

## 连接方式 {#connection}

有些网络连不上 Telegram 的服务器。网页版可以经 Luckgram 的中转连接，在 **设置 → Luckgram 功能 → 连接方式** 里选择：

| 选项 | 含义 | 什么时候用 |
|---|---|---|
| **自动**（默认） | 官方地址和中转谁先连上用谁 | 一般不用改 |
| **只用官方** | 只连 Telegram 的地址 | 不想让流量经过中转 |
| **只用中转** | 只经 Luckgram 中转连接 | 官方地址时通时断 |

同一页会显示当前走的是哪条线路。所有线路都连不上时，页面顶部会出现「无法连接，请检查网络」和 **重试** 按钮。

**中转能看到什么？** 中转只转发加密后的数据。消息内容由 Telegram 的协议在你的浏览器和 Telegram 的服务器之间加密，中转解不开，也不保存；它不记录 IP 地址，只统计连接数和流量。

## 常见问题 {#faq}

- **页面一直空白或停在加载：** 让窗口保持在前台。浏览器对后台或被遮住的标签页会暂停页面的启动。
- **登录页出来了但二维码很慢：** 多半是到 Telegram 的连接慢。等十几秒，或把连接方式改成 **只用中转** 再试。
- **收不到验证码：** 见上面的「验证码在哪里收」，或者改用扫码登录。
