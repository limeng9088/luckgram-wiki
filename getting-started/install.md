# How do I install Luckgram?

Start from the [official Luckgram download page](https://luckgram.me/download). It
is the canonical route when a store or package link changes.

## iPhone and iPad

Install [Luckgram from the Apple App Store](https://apps.apple.com/app/id1608870673).
The public source currently targets iOS 15 or later. Store availability and device
compatibility remain authoritative for the release you install.

## Android

Install [Luckgram from Google Play](https://play.google.com/store/apps/details?id=app.luckgram).
When Google Play is unavailable, the official download page also links to the
[latest public APK](https://github.com/luckgram/Luckgram-Android/releases/latest/download/app.apk).

The public Android project currently targets Android 7.0/API 24 or later. Your
store can impose a newer requirement for a particular release.

When installing an APK, Android may ask permission to install from that source.
Return that permission to its previous state after installation if you do not need
it for updates.

## macOS

Use the macOS download offered on the
[official download page](https://luckgram.me/download). Desktop feature parity is
not the same as mobile feature parity; check the [availability guide](availability.md).

## Source builds

Developers can inspect or build the public clients from
[Luckgram for iOS](https://github.com/luckgram/Luckgram-iOS),
[Luckgram for Android](https://github.com/luckgram/Luckgram-Android), and
[Luckgram Desktop](https://github.com/luckgram/luckgram-desktop). A source build is
not an official store release and can require private configuration or dependencies.
