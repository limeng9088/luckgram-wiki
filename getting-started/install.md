# 如何安装 Luckgram？

Luckgram 通过 GitHub Releases 发布。下面的链接始终指向最新版本。

## iPhone 和 iPad

安装 [Luckgram iOS 版（GitHub Releases）](https://github.com/limeng9088/luckgram-ios/releases/latest)。公开源码目前支持 iOS 15 及以上版本。具体能否安装、设备是否兼容，以你安装的那个版本为准。

## Android

安装 [Luckgram Android 版（GitHub Releases）](https://github.com/limeng9088/luckgram-android/releases/latest)。无法使用 Google Play 时，官方下载页面也提供[最新的公开 APK](https://github.com/limeng9088/luckgram-android/releases/latest)。

公开的 Android 项目目前支持 Android 7.0（API 24）及以上版本。个别版本在应用商店里可能要求更高的系统版本。

安装 APK 时，Android 可能会请求“允许安装来自此来源的应用”的权限。如果之后不需要用它来更新，安装完成后请把这个权限改回原来的设置。

## macOS

> **暂不提供。** 目前还没有 macOS 或其他桌面平台的 Luckgram 应用。在此之前，可以用同一个账号登录[Telegram Desktop](https://desktop.telegram.org)。

## 从源码构建

开发者可以查看或自行构建公开的客户端：[Luckgram iOS 版](https://github.com/limeng9088/luckgram-ios) 和[Luckgram Android 版](https://github.com/limeng9088/luckgram-android)。自行构建的版本不是官方发布版，需要你自己的 Telegram API 凭据和签名配置。
